# Penerjemah BISINDO

Proyek web sederhana untuk menerjemahkan teks dari bahasa Indonesia ke bahasa BISINDO dan sebaliknya.

## Fitur
- Antarmuka web sederhana
- Kamus data BISINDO
- Penerjemahan teks otomatis

## Cara menjalankan
1. Buka file `index.html` di browser.
2. Atau jalankan server statis lokal jika diperlukan.

## Teknologi
- HTML
- CSS
- JavaScript
